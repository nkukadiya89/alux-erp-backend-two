===============================================================================
PREREQUISITES:
===============================================================================

Before importing, ensure these records exist in your database:

1. ItemType records:
   - RAW
   - CONSUMABLE
   - SEMI
   - FG

2. ItemCategory records:
   - CAT001, CAT002, CAT003, CAT004

3. UOM records:
   - KG, MT, PCS

4. ValuationMethod record:
   - FIFO

5. MaterialCenter records (optional):
   - MC001, MC002, MC003

===============================================================================
KEY CHANGES FROM OLD FORMAT:
===============================================================================

1. Item Type is now a ForeignKey (not a choice field)
   - Must exist in ItemType table
   
2. Added 17 new columns for enhanced item management:
   - GST & Tax: HSN Code, GST Rate
   - Weight: Base Unit, Net Weight
   - Costing: Purchase Rate, Sale Rate, Valuation Method
   - Inventory: Minimum Stock, Maximum Stock, Reorder Qty
   - Production: Making Time Minutes, Lead Time Days, BOM Required, Material Center
   - Traceability: Batch Managed, GRN Required

3. Default values will be applied for missing optional fields
